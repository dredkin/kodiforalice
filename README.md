# Kodi Voice Assistant

Голосовой ассистент для управления медиацентром Kodi с поддержкой русского языка. Позволяет воспроизводить фильмы, сериалы и музыку через голосовые команды.

## Описание

Этот проект представляет собой Навык Алисы, который работает как webhook. Приложение умеет:

- Подключаться к Kodi по JSON-RPC API
- Искать фильмы, сериалы и музыку в медиабиблиотеке
- Воспроизводить контент по голосовым командам на русском языке
- Обрабатывать нечёткий поиск с использованием морфологического анализа

## Возможности

### Поддерживаемые команды
- **Воспроизведение**: "включи", "включить", "поставь", "поставить"
- **Просмотр**: "смотреть", "посмотреть" (для фильмов и сериалов)
- **Прослушивание**: "сыграй", "послушать", "слушать" (для музыки)

### Типы медиа
- **Фильмы**: фильм, кинофильм, кино, картина
- **Сериалы**: шоу, телешоу, сериал, серия, серии, эпизод
- **Музыка**: песня, композиция, трек, альбом, диск, группа

### Особенности
- Нормализация текста с помощью pymorphy3
- Поддержка римских цифр в названиях (II, III, IV и т.д.)
- Нечёткий поиск с использованием fuzzywuzzy
- Автоматическое воспроизведение первого непросмотренного эпизода для сериалов
- Фоновое обновление библиотеки и мониторинг состояния Kodi

## Установка

### Требования
- Python 3.7+
- Работающий Kodi медиацентр с включённым JSON-RPC API

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка Kodi

1. Откройте настройки Kodi
2. Перейдите в раздел "Службы" → "Управление"
3. Включите "Разрешить удалённое управление по HTTP"
4. Установите логин и пароль (по умолчанию: kodi/kodi)
5. Запомните порт (по умолчанию: 8080)

### Настройка приложения

Отредактируйте файл `config.py`:

```python
KODI_HOST = "192.168.1.100"  # IP адрес вашего Kodi
KODI_PORT = 8080             # Порт JSON-RPC API
KODI_LOGIN = "kodi"          # Логин
KODI_PASSWORD = "kodi"       # Пароль

PING_UPDATE_INTERVAL = 10    # Интервал проверки доступности Kodi (сек)
LIBRARY_UPDATE_INTERVAL = 300 # Интервал обновления библиотеки (сек)
```

## Запуск

```bash
python myapp.py
```

Приложение будет доступно по адресу `http://localhost:5000/webhook`

## Создание навыка для Яндекс Алисы

### Требования для деплоя
Для работы с Яндекс Алисой ваш webhook должен быть доступен из интернета. Варианты размещения:

### Настройка HTTPS (обязательно)
Яндекс Алиса требует HTTPS соединения.

### Создание навыка в консоли Яндекс Диалогов

1. **Регистрация**
   - Перейдите на [dialogs.yandex.ru](https://dialogs.yandex.ru)
   - Войдите через Яндекс ID или зарегистрируйтесь

2. **Создание навыка**
   - Нажмите "Создать навык"
   - Выберите тип доступа "Приватный"
   - Заполните основную информацию:
     - **Название**: "Kodi Медиацентр" (или любое другое)
     - **Активационное имя**: "коди" или "медиацентр"
     - **Описание**: "Управление медиацентром Kodi голосом"

3. **Настройка Webhook**
   - В разделе "Backend" → "Webhook"
   - **URL**: `https://yourdomain.com/webhook`
   - Нажмите "Сохранить"

4. **Активационные фразы**
   - Добавьте фразы активации:
     - "Включи фильм"
     - "Поставь сериал"
     - "Включи музыку"
     - "Смотреть кино"
     - "Послушать песню"

5. **Настройка интентов (опционально)**
   ```
   Интент: play_media
   Слоты:
   - media_type: фильм|сериал|музыка|кино|песня
   - title: {любое значение}
   
   Примеры фраз:
   - "включи {media_type} {title}"
   - "поставь {media_type} {title}"
   - "смотреть {title}"
   ```

### Тестирование навыка

1. **В консоли разработчика**
   - Используйте симулятор в консоли Яндекс Диалогов
   - Введите тестовые фразы: "Включи фильм Матрица"

2. **На устройствах**
   - Скажите: "Алиса, запусти навык Коди"
   - Затем: "Включи фильм Матрица"

### Примеры диалогов с Алисой

```
Пользователь: "Алиса, запусти Коди"
Алиса: "Я могу включить вам фильм, сериал или музыку."

Пользователь: "Включи фильм Матрица"
Алиса: "Включаю фильм Матрица."

Пользователь: "Поставь сериал Шерлок"
Алиса: "Найдено несколько сериалов: Шерлок, Шерлок Холмс. Что именно включить?"

Пользователь: "Шерлок"
Алиса: "Включаю сериал Шерлок."
```

## Разработка

### Добавление новых команд

Для добавления новых команд отредактируйте массив `commands` в `myapp.py`:

```python
commands = [
    {'id': ['новая_команда'], 'media': ['film', 'show'], 'words': {'новое_слово', 'синоним'}},
    # ...
]
```

### Добавление новых типов медиа

Для добавления новых типов медиа отредактируйте массив `media` в `myapp.py`:

```python
media = [
    {'media': ['новый_тип'], 'words': {'ключевое_слово', 'синоним'}},
    # ...
]
```

## Поиск и устранение неполадок

### Kodi недоступен
- Проверьте, что Kodi запущен и доступен по сети
- Убедитесь, что JSON-RPC включён в настройках Kodi
- Проверьте правильность настроек в `config.py`

### Медиа не найдены
- Убедитесь, что библиотека Kodi содержит нужный контент
- Проверьте, что сканирование библиотеки завершено
- Попробуйте более точные названия

### Ошибки поиска
- Проверьте логи приложения на наличие ошибок
- Убедитесь, что все зависимости установлены корректно
